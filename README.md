# CHROMA 四时 · The Four Seasons

一本私人季节穿搭手册。本仓库是「四季衣橱」方案的独立实现，与「色准色彩实验室」版是两个互不依赖的项目、两个独立仓库。

两版共用同一套色彩算法与数据结构，视觉语言和信息组织各自独立：本版为柔和自然色、圆角、自然光、温度与材质、四季层次拆解；另一版为中性白灰、1px 线框、等宽数值与可核对的配色矩阵。

## 已实现功能

- **四季为主轴**：顶部常驻季节滑动条；换季会同时改变推荐色域、明度与冷暖倾向、面料、穿衣层数、温度区间与服装品类，并生成对应的完整穿搭
- **颜色选择**：自然物色卡、柔和色环、HEX 输入、色相 / 鲜艳程度 / 明亮程度滑杆、从衣服照片本机取色（Canvas，图片不上传）
- **六种色彩关系**：同色系、邻近色、互补色、分裂互补、三角色、经典中性；底层按 HSL 角度计算，界面用「清透 / 沉稳」这类生活语言解释
- **每套提案包含**：完整自然光穿搭图、外层 / 中层 / 下装 / 鞋包 / 配饰的层次拆解、四段配色比例、适穿温度、推荐材质与层数、搭配理由、六件具体单品与替换方案
- **十种风格**：极简主义、静奢风、商务休闲、日系、韩系、美式休闲、街头风、复古风、Clean Fit、户外机能风
- **性别切换**：女士 / 男士切换后，人物廓形、单品名称与版型、风格标签、搭配理由同步变化，状态会被记住
- **私人档案**：收藏、历史记录、按季节筛选、颜色知识（含明度交互演示）
- **工程与可访问性**：移动端优先、零依赖零构建、键盘可达、可见焦点、44px 触控区、尊重 `prefers-reduced-motion`、无横向溢出；含加载/空/错误状态

## 本地运行

纯静态站点，直接双击 `index.html` 即可。或起一个本地服务：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## GitHub Pages

仓库 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。仓库根目录即为站点根目录，无需构建步骤。

## 文件结构

| 文件 | 职责 |
|---|---|
| `index.html` | 页面结构与真实文案 |
| `styles.css` | 视觉系统、响应式、状态与可访问性 |
| `core.js` | 色彩换算、六种关系、四季参数、男女版型 SVG、单品与知识数据 |
| `app.js` | 状态、渲染、交互、本地存储 |

## 说明

- 服装视觉为内联 SVG 矢量示意，用于准确表达版式、季节氛围与完整搭配关系；正式产品可替换为真实服装摄影，结构无需改动。
- 收藏与历史只存在浏览器 `localStorage`；图片取色仅在浏览器本地 Canvas 计算，不上传任何数据。
- 四季差异由参数与内容驱动，界面结构、字号与网格始终保持一致，避免变成四个不同网站。
